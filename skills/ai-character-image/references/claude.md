# Claude 角色约定

本文件维护 Claude 拟人角色的专属规则。通用生图流程与默认设置沿用 [Skill 主文件](../SKILL.md)。

## 名称与别名

以下称呼均指 Claude：`claude`、`Claude娘`、克劳德、克劳德大小姐。所有英文部分均不区分大小写，包括 `Claude娘` 中的英文部分。

识别到以上称呼时，直接按 Claude 处理，不再询问对应哪个 AI；这些称呼共用同一角色设定和相关参考图，不分别建立为不同角色。

## 形象参考路径

Claude 形象的参考图片目录为 Skill 根目录下的 `assets/reference-images/claude/`，相对于本文件为 `../assets/reference-images/claude/`。

生成或延续 Claude 拟人形象时，若用户未指定形象参考图，默认同时读取以下两张图片，共同作为形象参考：

- 正面图：`../assets/reference-images/claude/Front view.webp`。
- 三视图与设计参考表：`../assets/reference-images/claude/Three-view drawing & Design reference sheet.png`。

以上文件路径均相对于本文件。两张默认参考图都须实际查看，并在生图时共同传入工具，不只读取其中一张，也不自动改用目录内的其他图片。用户明确指定参考图或参考范围时，以用户要求为准。任一默认参考图缺失或无法读取时，如实说明具体文件，不声称已完整加载；后续按 Skill 主文件的缺失参考图规则处理。

## 角色一致性

- 同一 Claude 角色沿用已确认的设定和相关参考图，不因英文大小写不同建立新角色。
- 仅将本角色的图片用于身份参考；其他角色的图片只有在用户明确指定用途时才作为辅助参考。
- 画面文字保留用户指定的原文，不因名称归一化而替换。
- 尚未规定固定外貌、服装或头身比；生成时采用用户提供的设定、认可的参考图及通用默认值，不将临时设计称为官方人设。
